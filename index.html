      How deep in AI

      Deep enough to build and run LLM systems, not to train models. About 2 hours a day. Your angle is infrastructure: inference engines, model serving and vector search are written in C++ and reward systems experience.

      Know well enough to whiteboard

      • How LLMs work: tokens, context window, embeddings
      • Tool calling and structured output
      • RAG end to end: chunking, vector index, hybrid search, reranking
      • Agents: the tool loop, guardrails, human approval
      • Evals: test set, retrieval recall, LLM-as-judge
      • Production: latency, token cost, caching, fallbacks, prompt injection

      Build one project

      • An inference server in C++ on llama.cpp, with an HTTP API
      • Streaming, timeouts, cancellation, request batching
      • A vector index (hnswlib) and a RAG endpoint on top
      • An eval script in Python
      • Open models running on your own machine, so it costs nothing
      • On GitHub with measured numbers: time to first token, tokens per second, p95 latency, recall

      Skip for now

      • Training models from scratch
      • The maths and classical ML theory
      • Kaggle and research papers
      • Fine-tuning beyond knowing what LoRA is for

      Search job titles with "AI platform", "ML infrastructure", "inference" and "model serving".

      Money and offers

      • Decision date: 15 Feb. After it, accept the best offer on the table and keep interviewing from inside a job.
      • Give your last pay honestly. Ask for the range at the level before you name a number.
      • You can join immediately. Say so on the first call.
      • Tell every recruiter about your other processes. Overlapping offers are your negotiating power.
      • Ask for the full breakup in writing: fixed, variable, joining bonus, stock vesting.
      • Compare offers on fixed pay and guaranteed first-year cash before stock.
